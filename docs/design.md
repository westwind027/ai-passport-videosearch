以 FoloToy/folo-ai-passport-xiaozhi 为固件底座，在当前空目录中派生“语音视频搜索”版本。硬件目标固定为：
- ESP32-C3、8 MB Flash、无 PSRAM
- 240×320 ST7789P3
- ES8311 麦克风/扬声器
- GPIO0 ADC 三键
- CW2017 电量计
- 仅使用 ESP-IDF 5.5.5，目标 esp32c3
交互设计与赛博朋克 UI 规范
视觉风格定位为硬核赛博朋克（Cyberpunk 2077 / 军规战术终端 Netrunner HUD），彻底告别普通黑白方块，运用 45° 倒角切角、赛博黄（#FCEE0A）、电光青（#00F0FF）、霓虹赤红（#FF003C）高对比度色彩与战术标尺，完全遵循 ESP32-C3 极低内存和 LVGL 几何/纯色块渲染约束。高保真原型见 `docs/ui-mockups/cyberpunk-new.html`。

核心场景与页面定义：
1. 主页面流程链路：
   - 待命中：八边形 45° 切角战术反应堆罗盘，显示系统遥测（MEM/FREQ/VOLT）与语音输入引导卡片。
   - Wi-Fi 连接中：战术切角频段雷达扫描动效，显示目标 AP 与 WPA2/DHCP 握手状态。
   - 状态登录 / 小智对码：发光 6 位 PIN 码终端卡片与认证流转日志。
   - 语音识别中：霓虹赤红实时音频跳动电平光柱（VU Meter）与打字机流式 STT 呈现。
   - 搜索结果：96×64 切角缩略图框、时间码范围、相似度评分与语义摘要卡片。
2. 全屏展示（320×240 横向战术目镜 Optics HUD）：
   - ST7789 顺时针旋转 90 度，流式直写画面；覆以极轻量战术 HUD（REC 指示、时间码、四角瞄准线、中心十字准星与底部半透明场景字幕舱）。
3. 系统设置终端控制台：
   - 模块化切角卡片、数码级进音量推子、高亮反色焦点与服务连通性诊断。
4. 未配置 Wi-Fi 时的配置流程：
   - 离线断网警报：黄黑斑马危险纹理条（Hazard Stripes）与一键雷达扫描触发。
   - Wi-Fi 列表：信号强度阶梯分贝柱与加密/开放标识。
   - 6 列赛博机械矩阵键盘：30 键网格完美契合 GPIO0 三键 ADC（长按翻行、短按跳格、OK 输入）。

语音搜索流程：
OK短按
  → 小智音频通道录音
  → 收到最终 stt 文本
  → 屏幕立即显示识别文字
  → 终止小智后续 LLM/TTS 对话
  → 请求视频搜索服务
  → 下载并显示第一张结果图
  → 上/下键浏览其他结果
服务端默认请求 12 条结果，设备保留最多 12 条结果元数据，但始终只下载当前选中的一张图片。若响应超过 16 KB，或 JSON/结果元数据分配失败，客户端会在释放本次 HTTP、TCP 队列和响应体后按 `12 → 6 → 3 → 1` 重新请求；成功后展示降级结果，不把预期的内存压力升级为 `Search task ran out of memory`。
模块设计
采用几个小接口、深实现的模块：
- SearchApplication
  - 管理 Idle → Listening → Searching → Results/Error
  - 处理按键、菜单和并发搜索取消
  - 搜索状态单独管理，不破坏小智原有设备状态机
- XiaozhiRecognizer
  - 复用参考固件的 ES8311、Opus 和 WebSocket/MQTT
  - 监听 {"type":"stt","text":"..."} 事件
  - 每次讲话只产生一次最终搜索
  - 得到 STT 后关闭或 abort 对话，避免小智继续播报普通助手回答
- VideoSearchClient
  - 对上只暴露 Search(text) -> results
  - 内部完成 HTTP、JSON、相对图片 URL 拼接、超时和错误转换
  - 请求使用现有接口：
GET /v1/search?q=%E7%94%B7%E4%BA%BA&limit=12&mode=scene
设备端会对 UTF-8 查询词做 URL 编码。返回结构包括 query、results[].media_id、title、type、score，以及 scene.start、scene.end、scene.preview、scene.caption 等字段；scene.preview 作为结果图片 URL。绝对 URL 原样使用，相对路径则相对搜索服务地址解析。字段定义对应 `video-semantic-search` 服务中的 `internal/model/model.go` 和 `internal/api/server.go`。
- SearchDisplay
  - 独立构建主页面和菜单页面
  - 所有 LVGL 调用统一放到 UI 任务
  - 展示 ASR、加载状态、无结果、网络错误和图片
- DeviceSettings
  - 使用 NVS 保存音量、搜索服务地址和 Wi-Fi 凭据
  - Wi-Fi 列表扫描和连接复用现有 WifiManager/WifiStation，不启动旧的热点网页配网
- BatteryMonitor
  - 从 FoloToy/ai-passport 移植已经提供的 CW2017 驱动和 520mAh 电芯 profile
  - 地址 0x63，必须和 ES8311 复用现有 I2C0 bus handle
  - 实现小智 Board::GetBatteryLevel()；芯片缺失时显示 --，不阻塞启动
配网和服务端配置
长按 OK 进入菜单：
1. 音量
2. 网络配置
3. 服务地址配置
4. 返回
“网络配置”进入设备端 Wi-Fi 列表：上/下选择 SSID，OK 进入密码键盘。键盘完整沿用 leo-radio 的 6 列布局：大小写、数字/符号页切换，`<` 删除，`GO` 提交；短按上/下移动一个按键，长按上/下跨 6 个按键快速换行，OK 长按返回 Wi-Fi 列表。搜索地址直接进入同一套字符键盘，默认值是公开发布安全的占位地址 `http://video-search.local:8000`，选中 `GO` 保存到 NVS 的 `search/server_url`，OK 长按取消并返回设置。设置、音量、Wi-Fi 列表和字符键盘等所有子页面都遵循同一条父级返回规则；这些页面只替换主页的中间内容层，顶部应用栏和底部按键说明保持一致。

操作步骤：首次启动先在屏幕上选择 Wi-Fi 并输入密码；连接成功后设备自动进入小智激活/对码。若连接超时，会重新打开设备端 Wi-Fi 列表。日常修改服务地址则长按 OK → “服务地址配置”，在字符键盘中修改并选中 `GO` 保存。主界面只显示语音搜索词、搜索状态和结果图片，不显示小智对话消息。
图片方案
这是本项目最重要的技术约束。搜索结果图片 URL 支持服务端的三个尺寸档位：主页面请求 `?size=tiny`（最大 160×120），全屏查看请求 `?size=small`（最大 320×240）；固件会替换已有的尺寸参数，其中 tiny 额外限制为 80×60，small 使用服务端原生 small 尺寸。搜索接口返回的图片 URL 必须是设备所在网络可以直接访问的 URL。ESP32-C3 无 PSRAM，设备在首次显示图片时申请一个 12 KB JPEG 接收缓冲和一个 96×64 RGB565 解码缓冲，之后由所有搜索复用；全屏页面不申请 320×240 RGB565 整屏内存，而是启用 `esp_new_jpeg` block 模式，每次接收 8/16 行 MCU 数据后直接刷入 ST7789。全屏时临时切换 ST7789 的硬件坐标轴并顺时针旋转 90 度，使用 320×240 的旋转坐标空间刷图，因此不需要整屏转置缓冲；退出全屏后恢复原始显示方向。显示模块在刷屏前完成比例缩放，并可对图像做水平/垂直翻转。320×240 RGB565 原图仍需要约 150 KB，不能作为常驻缓冲和音频、Wi‑Fi、LVGL 同时驻留。
设备端：
- 一次只下载当前结果图片
- JPEG 下载最大限制 12 KB；下载阶段只检查编码 JPEG 是否能放入复用接收缓冲，HTTP 关闭后再独立检查 RGB565 解码缓冲区，避免把同一段内存预算重复计算
- 主页面解码到复用的 96×64 RGB565 缓冲；全屏仅保留一个不超过约 10 KB 的 JPEG MCU block 缓冲，解码一块显示一块
- 切换结果前释放上一张
- JSON 解析完成后先释放 JSON，再解码图片；每个结果的 cJSON 临时树使用 RAII 释放
- 禁止同时预加载多张
`esp_new_jpeg` 的缩放参数要求输出宽高为 8 的倍数，且最大缩小比例为 1/8；不满足这些条件的极端大图会被设备拒绝。无 PSRAM 的 C3 仍不会为原始大图分配完整 RGB565 缓冲区。
实施阶段
1. 固件基线
   导入参考仓库 v2.4.2-folo.1，保留 MIT LICENSE/NOTICE，使用 IDF 5.5.5 完成原版构建。
2. 硬件冒烟测试
   验证 LCD、三键 ADC、麦克风、扬声器、Wi-Fi 和 I2C 地址 0x18/0x63。
3. 搜索客户端闭环
   先用固定文字调用 GET /v1/search，显示标题和第一张缩略图。
4. 接入小智 ASR
   捕获最终 STT，取消普通助手回复并触发搜索。
5. 页面和菜单
   完成时间、网络、电池、结果浏览、音量、Wi-Fi 列表和服务地址输入；移除旧配网页面和小智对话页。
6. 稳定性处理
   增加请求超时、断网重连、重复 STT 去重、图片大小检查、低内存降级和服务地址测试。
7. 实机验收
   先读取芯片信息并备份现有固件，再烧录；测试中文语音、连续搜索、图片切换、掉线恢复和电池显示。
